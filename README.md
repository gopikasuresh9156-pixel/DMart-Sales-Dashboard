# DMart Sales and Inventory Dashboard

An interactive Power BI dashboard designed to analyze **DMart sales and inventory information**. The dashboard provides insights into product performance, sales, profit, stock levels, and inventory value.

### Sales Analysis

This page provides insights into total sales, profit, product performance, category-wise sales, and quantity sold. It helps understand which products and categories are performing well.

### Inventory Analysis

This page provides insights into stock quantity, inventory value, low-stock products, reorder levels, discounts, returns, and damages. It helps in monitoring inventory and identifying stock-related issues.

### Tools Used

- Power BI
- Excel
- Data Visualization
- Data Analysis

### Key Features

- Total sales and profit analysis
- Product and category analysis
- Sales performance tracking
- Inventory value analysis
- Stock level monitoring
- Low-stock product identification
- Discount and return analysis
- Interactive charts and filters
